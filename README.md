# 时光番库

按年代、类型和形式浏览 20 至 21 世纪的动画作品。站点收录 254 部作品，提供作品封面、简介、搜索和筛选，以及 Bangumi 社区评分与评分人数。评分为 Bangumi 数据快照，作品详情可跳转到原站查看。

## 本地预览

```sh
cd dist
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173/`。

## GitHub Pages

仓库的 `main` 分支每次更新时，`.github/workflows/pages.yml` 会发布 `dist/`。首次发布需要在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。

## 数据说明

作品资料与评分来自 [Bangumi](https://bgm.tv/)，封面与文字遵循原站的[版权说明](https://bangumi.tv/about/copyright)。网站不提供动画视频。数据是静态快照，评分不会实时同步。
